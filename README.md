# Cámara de Microempresas de Santa Elena

Sitio web institucional de la **Cámara de Microempresas de Santa Elena** (Ecuador),
gremio sin fines de lucro que agrupa, representa y fortalece a los microempresarios
de la provincia.

## Tecnología
Página web estática hecha con **HTML, CSS y JavaScript puro** (sin frameworks).
Funciona abriendo `index.html` en cualquier navegador.

## Estructura
- `index.html` — páginas (Inicio, Quiénes Somos, Servicios, Afíliate, Contacto)
- `styles.css` — estilos y diseño responsive
- `script.js` — navegación por vistas, menú, animaciones y formulario
- `assets/` — logos, imágenes y video de fondo
